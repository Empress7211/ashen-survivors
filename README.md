# Vampire Survivors · 灰烬之夜（Web HD Edition）

《灰烬之夜 · Ashen Survivors》是基于 TypeScript + Phaser 3.90 + Vite 构建的暗黑哥特自动战斗幸存者游戏网页重制版。采用手绘高对比暗黑哥特美术、Web Audio 程序化合成音乐与音效、固定 60Hz 确定性战斗模拟与 120Hz/144Hz 子帧平滑插值渲染。

---

## 核心特性

- **16 位独特猎魔英雄 & 关卡通关徽章**：从安东尼奥到死神（Red Death），每位英雄拥有专属初始武器、被动词条、等级成长曲线，以及全 5 大关卡的普通 / Hyper 通关徽章记录。
- **34 把武器与 14 项超武进化 / 联合**：包含 20 把基础武器与 14 把进化超武（如血泪、神圣魔杖、死神螺旋、双枪合体「菲拉吉」与双鸟合体「破坏者」），支持极限突破（Limit Break）。
- **16 种被动宝物与 12 张秘法塔罗牌（Arcana）**：自由搭配弹道反弹、治疗圣光、缺损生命狂暴等深度流派机制；战场与暂停装备栏支持悬停 / 聚焦查看属性与进化共鸣提示。
- **5 大高对比暗黑哥特战场**：疯狂森林、镶嵌图书馆（书架回廊）、乳制品厂、加洛塔（石柱长廊）与宏伟礼拜堂，支持 Hyper 狂热、Hurry 2x 时钟与 Endless 无尽轮回。
- **19 项永久祭坛强化 & 命运封印（Seal）**：支持 100% 全额退款重算递增费用；藏品图鉴内可封印未持有的基础武器或被动宝物（6–14 槽位随已解锁关卡扩展），精准构筑升级池。
- **完整局内与局外体验**：
  - 1 / 3 / 5 连宝箱光柱开箱演出、升级进化共鸣提示、战场右上角可开关实时小雷达（10Hz 刷新，含回廊边界、首领与银河系地图标记）及暂停魔导书进化矩阵。
  - 120Hz/144Hz 渲染插值配合投射物/区域对象池、零 GC HUD 快照与图集批处理，千怪同屏稳定流畅。
  - 实时 Boss 血条、中途成就达成横幅、复活抉择弹窗、结算分武器伤害 / DPS 统计表。
  - 怪物图鉴（28 种常规魔物与首领/死神）、45 项成就圣典、本地 JSON 存档导出 / 导入 / 重置。
  - 全程序化 Web Audio 合成器：6 首哥特管风琴 / 琶音 BGM 与全武器独立音色、拾取连击音阶及宝箱鼓点狂欢音效。
  - **PWA 离线畅玩 & 极速加载**：WOFF2 字体子集化、WebP 图标与单批世界图集压缩，结合构建生成的 Service Worker 与 `manifest.webmanifest` 支持离线运行与移动端刘海安全区适配。

## 操作指南

- **移动**：`WASD` / 方向键、游戏手柄左摇杆或十字键，或在战场画面按住拖动激活虚拟摇杆（武器自动释放）。
- **全界面手柄导航**：在主菜单、选角、选关、强化与暂停/选牌弹窗中支持手柄 D-Pad / 左摇杆二维空间焦点导航、`A` 确认、`B` 返回/关闭；升级选牌支持 `X` 重随、`Y` 放逐或跳过。
- **暂停 / 魔导书 / 地图**：`Space`、`Esc` 或手柄 `Start` 暂停/继续；暂停界面按 `G` 聚焦魔导书进化配方，`M` 聚焦银河系小地图，并可在设置或暂停菜单开关战场实时小雷达。
- **升级 / 秘法选牌**：点击卡牌或按数字键 `1`–`4` 选择；`R` 重随、`X` 跳过、`B` 切换放逐模式。
- **宝箱开启**：开箱动画 1 秒后可通过点击或按 `Space` / `Enter` / 手柄 `A` 收下全部战利品。

## 工程架构

```text
src/
├── contracts/   # 规范 ID 常量与跨层类型契约
├── data/        # 英雄、武器、被动、秘法、强化、敌人、关卡、成就与圣物目录
├── core/        # 确定性 60Hz 战斗模拟（GameSimulation）、空间哈希、波次导演与 SaveStore
├── audio/       # Web Audio 多声部合成器与阶段 BGM 调度器（AudioEngine）
├── render/      # Phaser 3.90 WebGL2 渲染器（BattleRenderer）
├── ui/          # 暗黑哥特菜单、HUD、选牌、宝箱、暂停魔典地图与结算界面
├── app/         # 主应用壳层（AppShell）、战斗循环调度（BattleController）与输入聚合
└── styles/      # 暗黑哥特设计系统（Cinzel + Noto Serif SC）
```

## 本地开发与验证

需要 Node.js 20+。

```sh
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 运行核心单元测试（目录、音频与战斗模拟）
npm test

# TypeScript 严格检查与生产构建
npm run build

# 预览生产构建
npm run preview
```
